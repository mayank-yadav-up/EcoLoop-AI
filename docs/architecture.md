# EcoLoop AI Architecture

## Workflow

Sensors → Building Simulator → AI HVAC Agent → Decision Engine → Dashboard

### Components

1. Building Simulator

Generates environmental data including temperature, humidity, occupancy and energy usage.

2. AI HVAC Agent

Analyzes sensor data and recommends HVAC optimization strategies.

3. Dashboard

Displays live sensor values, AI recommendations, estimated savings and system health.
