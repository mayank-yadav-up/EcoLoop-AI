# EcoLoop AI

## Overview

EcoLoop AI is an autonomous smart building controller developed for the Honeywell Hackathon.

The system simulates a Building Management System (BMS) where an AI agent continuously monitors building conditions and recommends HVAC control actions to improve energy efficiency while maintaining occupant comfort.

---

## Features

- Live Building Sensor Dashboard
- Autonomous HVAC Decision Agent
- Energy Consumption Monitoring
- Estimated Energy Savings
- CO₂ Reduction Estimation
- Closed Loop Control Simulation
- Streamlit Dashboard
